# Excel-Dashboard-Project

#  BigMart Sales Analysis Dashboard (Excel)

##  Project Overview

This project showcases an interactive **BigMart Sales Dashboard** built in **Microsoft Excel** to analyze supermarket sales performance, outlet distribution, product categories, customer preferences, and inventory characteristics.

---

#  Business Problem Statement

This dashboard was designed to answer key business questions such as:

### Sales Performance

* Which years generated the highest sales revenue?
* Which outlet types contribute the most to total sales?
* Which outlet locations perform best?

### Product Analysis

* Which product categories generate the highest sales?
* Which products have the highest MRP contribution?
* What is the distribution of item weights across categories?

### Store Analysis

* How many outlets exist by outlet type?
* Which outlet sizes generate the highest revenue?
* Which store formats are most profitable?

### Customer Preferences

* Do customers prefer Low Fat or Regular products?
* Which categories are purchased most frequently?

---

#  Dashboard KPIs & Analysis Areas

The dashboard focuses on:

* Total Sales by Year

#  Key Findings & Insights

## 1. Outlet Type Performance

### Finding:

Supermarket Type 1 dominates both sales and outlet count.

| Outlet Type        | Sales   |
| ------------------ | ------- |
| Supermarket Type 1 | 748,946 |
| Supermarket Type 3 | 442,796 |
| Supermarket Type 2 | 195,710 |
| Grocery Store      | 20,765  |

### Insight:

* Supermarket Type 1 contributes the largest share of revenue.
* Grocery Stores contribute minimal sales compared to supermarkets.
* Expanding Type 1 outlets could drive further growth.

---

## 2. Outlet Count Analysis

### Finding:

| Outlet Type        | Count |
| ------------------ | ----- |
| Supermarket Type 1 | 655   |
| Supermarket Type 3 | 125   |
| Grocery Store      | 124   |
| Supermarket Type 2 | 96    |

### Insight:

* Type 1 outlets not only generate the highest revenue but also have the widest presence.
* Store expansion strategy appears heavily focused on Type 1 outlets.

---

## 3. Outlet Size Analysis

### Finding:

Medium-sized outlets generate the highest overall sales.

### Insight:

* Medium-sized stores appear to provide the best balance between operational cost and revenue generation.
* Large-format stores do not necessarily outperform medium-sized outlets.

---

## 4. Location Tier Analysis

### Finding:

| Location Tier | Total Sales |
| ------------- | ----------- |
| Tier 3        | 899,190     |
| Tier 2        | 765,160     |
| Tier 1        | 526,291     |

### Insight:

* Tier 3 cities generate the highest sales.
* Emerging markets are contributing significantly to overall business growth.
* Future store expansion may yield better ROI in Tier 2 and Tier 3 locations.

---

## 5. Product Category Sales Analysis

### Top Performing Categories:

1. Fruits & Vegetables
2. Household Items
3. Frozen Foods
4. Baking Goods
5. Soft Drinks

### Insight:

* Fruits & Vegetables are the highest-selling category.
* Essential household products continue to drive consistent revenue.
* Daily-consumption products dominate customer purchases.

---

## 7. Item Weight Analysis

### Finding:

Categories such as Fruits & Vegetables, Snack Foods, Household Products, and Frozen Foods account for the highest cumulative product weight.

---

## 8. Item MRP Analysis

### Finding:

Higher MRP contribution comes primarily from:

* Fruits & Vegetables
* Snack Foods
* Household Products
* Dairy Products

### Insight:

* Premium-priced products contribute significantly to overall revenue.
* Product pricing strategy appears effective within these categories.
